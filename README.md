# 基于YOLOv8-s的高寒地区道路智能养护一体化方案

> 面向高寒地区路面病害检测、风险评估与养护决策的一体化智能系统

## 系统概述

本系统基于 YOLOv8-s 目标检测算法，针对高寒地区（青藏高原、东北寒区等）道路养护需求，构建了一套**病害检测 → 风险评估 → 养护决策**的一体化解决方案。

### 核心能力

| 模块 | 功能 | 技术手段 |
|------|------|----------|
| 病害检测 | 识别13类路面病害（含5类高寒特殊病害） | YOLOv8-s 深度学习 |
| 风险评估 | 冻融循环、冻胀、冰雪、盐冻四维风险 | 多因素加权评估模型 |
| 养护决策 | 自动生成养护方案、优先级排序、成本估算 | 规则引擎 + 专家知识库 |
| Web 平台 | 可视化界面，支持图片上传与环境参数配置 | Flask + 原生前端 |

### 高寒地区特殊病害

本系统在常规8类路面病害基础上，新增5类高寒地区特有病害：

- **冻融裂缝** — 冻融循环导致的温度裂缝
- **冰冻隆起** — 冻胀引起的路面隆起变形
- **冻胀坑槽** — 冻融破坏形成的坑槽
- **冰雪覆盖** — 冰雪覆盖影响道路安全
- **盐冻剥蚀** — 除冰盐导致的路面剥蚀

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动 Web 服务

```bash
python web/app.py
```

浏览器打开 http://localhost:5000

### 3. 命令行检测

```bash
python scripts/predict.py --input 路面图片.jpg --temperature -15 --road "G214线K100段"
```

### 4. 模型训练（如有数据集）

```bash
python scripts/train.py --data data/datasets/road_disease.yaml --epochs 100 --device 0
```

## 技术方案

### 检测算法：YOLOv8-s

- **模型选择**：YOLOv8-s（Small版本），在精度与速度间取得最佳平衡
- **输入尺寸**：640×640
- **检测类别**：13类路面病害
- **训练策略**：迁移学习，基于 COCO 预训练权重微调
- **数据增强**：HSV 色彩扰动、随机旋转、Mosaic、MixUp

### 高寒地区风险模型

系统采用多因素加权评估模型，综合考虑：

1. **冻融循环风险** — 冻融次数 → 裂缝扩展加速
2. **冻胀损坏风险** — 冻土深度 + 道路年限 → 结构性损坏
3. **冰雪覆盖风险** — 冰层厚度 + 冻结天数 → 通行安全
4. **盐冻剥蚀风险** — 湿度 + 除冰盐用量 → 表面剥蚀

### 养护决策引擎

- **病害严重程度分级**：轻微 / 中等 / 严重 / 极严重
- **养护方法库**：覆盖13类病害 × 4级严重程度 = 52种养护方案
- **优先级排序**：1-5级，紧急病害自动标记
- **成本估算**：基于面积 × 单价模型
- **高寒特别提示**：每类病害配套高寒地区施工注意事项
