## 二、模块设计

### 2.1 病害检测模块 (detector.py)

```
RoadDiseaseDetector
├── __init__(config)        # 初始化，加载模型
├── detect_image(path)      # 单图检测
├── detect_video(path)      # 视频检测
├── detect_batch(dir)       # 批量检测
├── _load_model()           # 模型加载
├── _generate_summary()     # 检测摘要
└── _get_max_severity()     # 最大严重程度
```

**输入**：路面图片 (JPG/PNG/BMP)
**输出**：检测结果（病害列表 + 标注图 + 统计摘要）

### 2.2 高寒地区分析模块 (cold_region.py)

```
ColdRegionAnalyzer
├── analyze_environment(env)           # 综合风险评估
├── _assess_freeze_thaw(cycles)       # 冻融循环风险
├── _assess_frost_damage(env)         # 冻胀风险
├── _assess_ice_snow(env)             # 冰雪风险
├── _assess_salt_erosion(env)         # 盐冻风险
├── get_temperature_factor(temp)      # 温度影响因子
├── adjust_severity(severity, env)    # 调整严重程度
└── get_maintenance_window(env)       # 养护窗口判断
```

**数据结构**：
- `ColdRegionInfo` — 环境参数输入
- `ColdRegionRisk` — 风险评估结果

### 2.3 养护决策模块 (maintenance.py)

```
MaintenanceDecisionEngine
├── generate_plan(detections, env)        # 生成养护方案
├── _determine_severity(disease, env)     # 病害严重程度
├── _generate_recommendations(tasks, env) # 养护建议
├── MAINTENANCE_METHODS                   # 养护方法库(52种)
├── PRIORITY_THRESHOLDS                    # 优先级阈值
└── COLD_REGION_NOTES                     # 高寒注意事项
```

**数据结构**：
- `MaintenanceTask` — 单个养护任务
- `MaintenancePlan` — 完整养护方案

### 2.4 Web 服务模块 (app.py)

```
Flask App
├── GET  /           # 首页
├── POST /detect     # 图片检测
├── POST /batch      # 批量检测
└── GET  /health     # 健康检查
```

## 三、数据流

### 3.1 检测流程

```
用户上传图片
    │
    ▼
Flask 接收文件 → 保存到 uploads/
    │
    ▼
YOLOv8-s 检测 → 返回检测结果(boxes, conf, cls)
    │
    ▼
格式化结果 → 病害列表(disease_name, confidence, bbox, area)
    │
    ▼
风险评估 → 冻融/冻胀/冰雪/盐冻四维评分
    │
    ▼
养护决策 → 养护任务列表(方法, 成本, 工期, 优先级)
    │
    ▼
返回 JSON → 前端渲染
```

### 3.2 严重程度判定逻辑

```
面积比 + 置信度
    │
    ▼
基础严重程度(轻微/中等/严重/极严重)
    │
    ▼
温度因子修正 ← 当前温度
    │
    ▼
冻融风险修正 ← 冻融循环次数
    │
    ▼
最终严重程度 → 查养护方法库 → 生成养护任务
```

## 四、配置管理

系统配置统一由 `config/config.yaml` 管理：

```yaml
model:          # 模型参数
  name, weights, imgsz, conf, iou, device

classes:        # 常规病害(8类)
cold_region_classes:  # 高寒病害(5类)

detection:      # 检测参数
  imgsz, conf_threshold, iou_threshold, max_det

maintenance:   # 养护阈值
  severity_levels: minor/moderate/severe
  temperature: freeze_threshold, severe_cold, construction_min

server:        # Web 服务
  host, port, debug

dataset:       # 数据集路径
  train, val, test
```

## 五、扩展性设计

1. **病害类别可扩展**：修改 config.yaml 即可增加新类别
2. **养护方法可扩展**：在 MAINTENANCE_METHODS 中添加新方案
3. **风险维度可扩展**：ColdRegionAnalyzer 支持新增风险因子
4. **部署方式可扩展**：支持本地、Docker、云端部署
